hey! Let's create a project that helps the content creators practice gestures, body movements and giving visual hooks. 

tech stack - 
frontend - react + plain css + framer motion for animation and effects
backend - fastapi
database - mongodb
ai - agno library for multimodal (refer to code here - D:\Arpit\Study\agentic\agno)

UI - create neumorphism and cyber punk UI with animations but do not bloat them up by using lots of gradients. it has to be little minimalisic only on this theme


in this project we'll have the following components - 
1) home page (only when the user is not logged in)
consists of -
navigation bar containing details, features, pricing, log in
#features - showcase the features and capabilities of the website
#details - it lists down the steps about how to use the product.
footer - about us, why this product
associated pages -
/about - this page consists of information about the creator of the project - Arpit Thakur from IIT Patna, lives in Noida. late on i'll tell you what more details to add for this
/why-us - this project tells the necessity of this product. particularly that when u record videos by yourself and review it again and again by watching it takes lot of time to figure out the mistakes and the gallery gets piled up with huge amount of videos and stuff
/login - this asks for the email and password of the user. for now let's keep it simple. we'll be using JWT and no OTP verification.


2) dashboard (when the user is logged in)- 
this consists of the following sections - 
idea recommendations - this consists of an AI chat where the user can ask for help for scripting and the corresponding gestures. the output of the LLM has to be of the format {{text: gesture/movement/pitch idea}}. this idea will not simply be displayed as chat but in well structured format containing cards for text and then an arrow and then card for gesture idea. the user can give only one prompt only and then he has the option to restart the session. then response then gets stored in the backend which can be seen from /ideation.
previous - this shows cards for the previous practice sessions of the user which redicts them to /history/sessionid
there is a center aligned circle shaped fixed plus button at the bottom of the screen hovering on which says create new practice session. this takes the user to /practice.

2) practice - in the center of the screen there is web cam recording being displayed. there is a start recording below it. below this there is option to load any chat from /ideation in the form of a dropdown. the chat then loads on the screen below the recording window. this is for the reference of the user.
once the user clicks stop recording the recording gets saved and goes to agno for review and the user is taken to /history/sessionid. this page consist of the recording, the review of form the multimodal and the ideation chat if the user had chosen any.
there is option to delete practice session also.

3) ideation - this page (/ideation) shows the ideation response in that structured format that the AI gave. there is option to delete an ideation as well

keep the code simple, do not make unnecessary imports.
